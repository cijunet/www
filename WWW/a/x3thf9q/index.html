Youth is the only treasure that never returns.

萧伯纳 英国·19世纪 极短

遇到懂你的人1

你有一个苹果，我有一个苹果，交换后每人还是一个苹果。但如果你有一种思想，我有一种思想，交换后每人就有两种思想。

If you have an apple and I have an apple and we exchange, we each still have one apple. But if you have an idea and I have an idea, we each have two.

交换思想，各得两种。

萧伯纳 英国·19世纪 偏长

怎么用交换苹果各得一个，交换思想各得两种；谈思想交流、智慧共享时用。
