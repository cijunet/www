杜牧 《江南春》 唐 适中

怎么用江南春景的广角镜头，配航拍或古镇。

春天刚来的时候花开了、花落了
停车坐爱枫林晚，霜叶红于二月花。
杜牧 《山行》 唐 适中

怎么用看红叶的标配，配满山枫叶。

入秋、落叶、秋高气爽
银烛秋光冷画屏，轻罗小扇扑流萤。
杜牧 《秋夕》 唐 适中

怎么用秋夜的幽静，配萤火虫或夜灯。

入秋、落叶、秋高气爽夜里的星空与月亮
江东子弟多才俊，卷土重来未可知。
杜牧 《题乌江亭》 唐 适中

年轻、意气风发摔倒了还想再来一次
十年一觉扬州梦，赢得青楼薄幸名。
杜牧 《遣怀》 唐 适中

怎么用多年后回望一段旧事，配老街。

很多年后重逢三十岁、四十岁的坎
稚子牵衣问，归来何太迟。
